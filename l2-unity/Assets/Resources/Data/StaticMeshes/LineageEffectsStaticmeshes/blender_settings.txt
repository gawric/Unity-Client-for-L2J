Перейдите в Object Mode (нажмите Tab).Нажмите правую кнопку мыши по трубе.Выберите 
Set Origin ➔ Origin to Geometry (Blender сам вычислит точный центр этой трубы и поставит пивот туда).
Нажмите Shift + S ➔ выберите Cursor to World Origin (сбросит 3D-курсор в идеальный ноль сетки).
Снова нажмите Shift + S ➔ выберите Selection to Cursor (труба со своим новым правильным центром присосется ровно в центр осей).
