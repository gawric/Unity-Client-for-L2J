# Doc

## Назначение

Создавай короткую, переиспользуемую документацию по текущей работе с эффектами (особенно `el_ice_bolt`) с фокусом на:
- что изменилось;
- почему это изменилось;
- что сейчас уже работает;
- что настраивать дальше.

## Правила оформления

1. Пиши кратко и по делу.
2. Предпочитай пути проекта и конкретные имена параметров.
3. Разделяй:
   - **Итоги за сегодня** (уровень хронологии),
   - **Текущее описание шейдера** (уровень реализации),
   - **Следующие шаги** (список действий).
4. Не вставляй длинные сырые логи, если пользователь явно не просил.

## Структура по умолчанию

Используй такую структуру:

```md
# <Заголовок>

## Итоги за сегодня
- ...

## Текущее поведение шейдера
- ...

## Текущее соответствие материал/эмиттер
- ...

## Следующие шаги по настройке
- ...
```
